# ⚡ EchoFlink

Anonymous chat & voice rooms – no login, via WebRTC.

- Create a room and share the invite link
- Public groups with real‑time messaging
- Voice rooms inside each group (click 🎙️)
- Dark mode, emoji reactions, message search, save/load room
- Fully peer‑to‑peer (PeerJS), encrypted voice (DTLS‑SRTP)

## 🛠️ Tech

- **PeerJS** (1.5.1) for signalling & WebRTC
- Pure HTML/CSS/JS – no frameworks
- Hosted easily on GitHub Pages
